# Release Evidence — Core 3.0.0

This directory contains evidence reports generated by the evaluation pipeline
for the Core 3.0.0 GA release.

## Files

| File | Description |
|------|-------------|
| `contract-oracle-evidence.json` | Pull-request tier evidence from contract oracle (9 corpora, all PASS) |
| `contract-oracle-v1.json` | Prediction bundle from contract oracle |
| `contract-oracle-scheduled.json` | Scheduled tier prediction bundle |

## How to regenerate

```bash
# Validate corpora
cargo run -p latexsnipper-evaluation --bin ocr-eval -- \
  validate --index evaluation/corpora/index.json

# Generate predictions
cargo run -p latexsnipper-evaluation --bin ocr-eval -- \
  contract-predictions \
  --index evaluation/corpora/index.json \
  --tier pull-request \
  --model-spec evaluation/contract-oracle-v1.json \
  --output release-evidence/contract-oracle-v1.json

# Evaluate against gates
cargo run -p latexsnipper-evaluation --bin ocr-eval -- \
  evaluate \
  --index evaluation/corpora/index.json \
  --predictions release-evidence/contract-oracle-v1.json \
  --gates evaluation/gates/pull-request.json \
  --tier pull-request \
  --source-commit $(git rev-parse HEAD) \
  --generated-at-utc $(date -u +%Y-%m-%dT%H:%M:%SZ) \
  --output release-evidence/contract-oracle-evidence.json
```
