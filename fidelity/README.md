# Office and PDF fidelity evidence

`fidelity/corpora/index.json` is the executable, checksum-pinned golden corpus
index. The four compact fixtures are generated by:

```bash
cargo run -p latexsnipper-fidelity --bin generate-fidelity-fixtures
```

Validate and execute the evidence gates with:

```bash
cargo run -p latexsnipper-fidelity --bin fidelity-check -- \
  validate --index fidelity/corpora/index.json --repository-root .
cargo run -p latexsnipper-fidelity --bin fidelity-check -- \
  run --index fidelity/corpora/index.json --repository-root . \
  --source-commit local --generated-at-utc unspecified \
  --output target/fidelity/report.json
```

The report always separates structural validity, semantic preservation, layout
preservation, visual fidelity, editability, and round-trip fidelity. A skipped
visual or application layer is recorded as skipped, never passed. In particular,
successful ZIP/PDF reopening is only structural evidence and does not establish
visual parity in Microsoft Office, LibreOffice, or a PDF viewer.

All fixtures are deterministic repository-generated test data under AGPL-3.0.
They contain no personal data or external assets.
