# Core 与 Office 收尾计划

更新：2026-10-05。只记录当前任务；执行记录留在报告和宿主验收文档，不在计划中重复。

## 已有基础

Core 已有统一转换能力投影、固定语料报告、包级回读，以及 Rust/C/Python/JSONL 的进程内会话复用。
Office 已有自定义符号混合预览、绘图边界修复、源码结构着色、主题控件、
上下文补全和部分真实 Word 格式转换。桌面程序已更新，但安装载荷尚未统一到同一版本。

这些基础不代表所有格式、宿主和安装环境均已完成。

## 暂缓项

- Zig：现有隔离试点未达到接入收益要求；只有新热点与跨平台分析支持时再启动。
- 全面替换 MathLive/KaTeX：先完成现有混合符号、字体与输出链路，不并行重写整个公式引擎。
- MTEF 写入与完整 MathType 兼容：在只读语义、规范和许可边界明确后单独立项。
- CLI daemon 与生成式公式续写：按实际需求和收益决定，不阻塞当前收尾。

## 下一步

先处理安装信任与同源打包，同时继续不依赖信任的批量性能和 Core 格式工作；
之后完成多宿主与 OCR 闭环，最后汇总发布说明。每完成一项只更新状态与下一步，不追加测试流水账。
