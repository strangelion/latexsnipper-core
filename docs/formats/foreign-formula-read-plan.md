# 第三方 OLE 与图片的公式源读取

更新：2026-10-07。FMT-08，基础只读支持；不是任意软件 OLE 编辑兼容。

## 当前基础

DOCX reader 已可读取原生 OMML 并保留原片段；重建的 LaTeX 不等于原源码。
MTEF v5 raw 检查已有批次精确去重及记录结构相似分组，尚无语义转换。
第三方 OLE 容器、图片源码元数据与通用宿主入口仍未接通。

## 顺序与责任

| 顺序 | 能力 | 责任与下一步 |
| --- | --- | --- |
| P0 | 读取边界 | Office 的 OLE 自动化读取先限定本应用身份；第三方对象从包/流只读检查，不访问其 Object 或执行激活 |
| P1 | 明确源码元数据 | Core 接收带来源、对象关联与范围的候选；支持有限 LaTeX/MathML/OMML，返回原文、诊断和损失信息 |
| P1 | 图片基础支持 | 有限 PNG 文本/XMP、SVG metadata/MathML annotation 适配；普通替代文字只作提示，纯像素图片转入可选 OCR |
| P1 | MTEF 与容器 | Office 提取有边界的嵌入流；Core 按版本诊断、去重并逐步映射有限 AST，未知记录/旧版保留原始数据 |
| P1 | 加载项入口 | 在 Word 选区及文档清单直接“读取公式源”，显示原始源码/重建/OCR 的区别；转换需预览与确认，不要求无谓返回桌面程序 |
| P2 | 快速再读取 | 文档修订、对象/关系与源哈希绑定索引；精确内容决定复用，结构相似只供分组 |

## 保留边界

- 不启动第三方 OLE 服务器，不覆盖原对象；读取不需要伪造 MathType 对象身份。
- 只提取与所选对象明确关联的源码，不在二进制中用正则搜到一段文本就当公式。
- 源码、字体、宏、样式来源分开保留；多个来源冲突时展示诊断，不静默选取或覆盖。
- ZIP/CFB/图片元数据有条目、字节、深度与解压预算；禁止外部关系访问、路径逃逸、XML 外部实体与脚本执行。
- 存储容器与公式格式分别判断；缺少源码明确标注不可恢复或需 OCR，不承诺无损恢复。
- 正式支持按适配器/版本列出；MTEF 语义与写入沿用 [FMT-06 门禁](mtef-readonly.md)，真实第三方样例需明确来源与分发许可。
