# LaTeX 注释、定界符与字面字符

更新：2026-10-09。属于 FMT-02/FMT-04 的有限语法和源信息工作，不是完整 TeX 编译器。

## 已实现

- 默认 catcode 下的未转义 `%` 注释支持 LF、CRLF、CR 和 EOF。
  分式/脚本参数、根号可选参数、矩阵及常用环境的头部和正文忽略注释中的假操作数、括号、列/行分隔符及结束标签。
- 文档公式发现不把注释中的 `$`、`$$`、`\(...\)`、`\[...\]` 当成公式；注释中的关闭标记不会截断已有公式。
  原始公式内容与 UTF-8 字节 source-map 区间保留，渲染语义与原始源码分开处理。
- `\%`、`\&`、`\#`、`\_`、`\$`、`\{`、`\}` 保留为字面字符，数组列规格仍单独保存原始注释，不混入数学内容。
- XML 读入的可见元字符重建为转义 LaTeX，避免可见 `%` 吞掉后续公式、`&` 变成列边界或花括号变成分组。
  反斜杠、`^`、`~` 也使用有限字面命令重建；XML 中的 `\frac` 文字不能借此变成活动分式。
  OMML→共享布局的 canonical LaTeX 同样保护这些字符。
- OMML 文本命令从原始文本参数输出，XML 元字符只编码一次；`\text{a\%b\&c<d>}` 不再把 `&` 展示成实体字符串。
- 控制词后分隔空白不再成为 OMML 可见文字；canonical 片段之间保留必要的控制词边界，避免 `\alpha` 与 `x` 合并成 `\alphax`。
  片段拼接和注释扫描为线性遍历，不反复扫描全部已拼接前缀。
- 只有注释/空内容、缺失上下标操作数不能严格替换。严格源字节/复杂度/嵌套预算保留；注释中的假命令和括号不消耗语义复杂度。
- 未知环境保留整段原文并拒绝严格 OMML 转换，不把 verbatim 内容部分解释成已转换数学。已有 `document` 包装的普通往返保持兼容。
  普通 `\left...\right` 扫描避开注释中的假 `\right`，并移除原先动态右定界符的字符串泄漏。

## 边界与兼容性

不执行宏，不支持动态 catcode、verbatim 的排版/执行或包级语义；未知环境是原文占位，不是成功排版。
复杂/嵌套/命名的可伸缩定界符、星号多行环境、高级 array 与完整文本宏仍需继续完善。
此批重建会添加转义和必要的命令分隔；XML→LaTeX 不是原源码恢复，调用方仍应保留原 XML 和重建来源标记。
混合 Markdown 代码块沿用独立解析器，不使用本次 TeX 注释规则去修改代码块。
源字节预算不会因删除注释而放宽，超过原始输入预算仍拒绝。
