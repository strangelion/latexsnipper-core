# 个性化公式补全与辅助续写计划

更新：2026-10-05。“选择器”指候选排序方法，不假定 jev 是已确认的具体模型。

## 当前基础

Office 已有命令/环境/上下标模板、有限光标上下文联想和有效保存符号候选。
最佳候选以淡字显示，Tab 接受、Esc 隐藏、Ctrl+Space 唤出，接受可一次撤销。
菜单跟随深浅主题；本地频率/最近使用排序默认关闭，可关闭和清空。
当前没有具体学习模型、AST 槽位补全或生成式续写。

## 下一步

| 顺序 | 工作项 | 交付范围 |
| --- | --- | --- |
| 1 | 结构化联想 | AST 槽位、当前环境、花括号/上下标/矩阵占位符与跳转；不完整输入仍有有限建议 |
| 2 | 自定义符号与片段 | 候选关联定义 ID/版本；按用户授权从公式库/历史检索，显示来源，不插入未定义宏 |
| 3 | 偏好隔离 | 用户与项目/文档分层，敏感文档不学习，支持清空、重置与受控导入/导出 |
| 4 | 轻量选择器 | 比较固定排序、频率/最近使用和在线线性排序；依据接受、撤销和实质修改，而非展示或悬停 |
| 5 | 受控续写 | 优先模板/检索续写；只有前述方法收益不足时才评估可选小生成模型 |

## 实现边界

- Core 保持确定性语法、资源预算、支持范围和损失检查；偏好分数不能绕过这些检查。
- 建议绑定当前编辑版本，迟到结果不得覆盖新输入；宿主负责选区、事务和写入确认。
- 默认不上传公式；只保存最小化、有界、可解释的反馈，不持久化原始公式或私有符号名。
- 模型、历史或存储失效时回退确定性补全，不阻塞编辑、渲染和转换。
- 真实 IME、长文档响应与实际节省输入的收益尚待确认，不能把候选数量当学习效果。
- 续写不代表数学证明；不自动替换已有公式或写入 Office，不添加强制推理依赖。

本项可与格式补全并行，但不阻塞安装信任和真实宿主闭环。
