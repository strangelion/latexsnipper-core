# 个性化公式补全与辅助续写评估

状态：2026-10-05 Office 源码已有默认关闭的本地排序试点；Core 本身未接入模型。
这里的“选择器”指一类候选排序/偏好学习方法，不假定 `jev` 是已确认的具体模型。
本项不阻塞 FMT 格式补全、OLE/图片真实宿主验收或已有 CI 修复。

## 2026-10-05 有限试点与剩余门禁

Office 源码编辑器已为既有固定命令候选提供显式 opt-in 的频率/最近使用权重。
只接受补全提交反馈，立即撤销回退；关闭停止学习，清空恢复冷启动。持久化仅含
有界候选索引/统计和固定公共目录，不包含用户公式、文档或上下文，不上传。
存储不可用/损坏/目录改变时回退固定候选，完整公式仍沿用现有转换校验。
4 项 Node 单测和真实浏览器接受/撤销、排名、重载、清空与文本不落库回归通过。
新源码尚未进入安装版桌面程序；不是具体 `jev` 模型集成或学习质量证明。
Office 实现提交 `9909ad6`；对应命令为 `node --test tests/completion-selector.test.mjs`
和 `node scripts/verify-completion-selector.mjs`（需要本地应用服务）。

本轮只落地阶段 2 的最小可关闭基线；阶段 1 的 AST 槽位/自定义符号、文档/项目隔离、
IME 与长文档、Top-1/Top-3/MRR、节省击键和模型比较仍待验收。三候选微基准低于
浏览器计时粒度，不能据此关闭 P95 <=50 ms 目标。受控续写和生成模型未实施，
不随机探索、不自动写入 Office、不改变 Core 注册表或引入强制推理依赖。

## 目标与非目标

提高符合个人/当前文档习惯的命令、符号、片段和下一段公式建议，例如常用
`\frac` / `\dfrac`、向量写法、积分微分符号、矩阵环境、自定义符号与已保存模板。
不要为了习惯而改变原公式语义；错误语法不能靠高偏好分数绕过 Core 检查。
候选排序不等于生成任意公式，语法通过也不等于数学结论正确。

可参考 [Vowpal Wabbit 的 contextual-bandit 个性化教程](https://vowpalwabbit.org/tutorials/cb_simulation.html)：
利用上下文、候选行动及反馈调整选择。此处只是方法参考，未决定引入该依赖。
将它用于公式补全的收益是假设，需要本应用数据验证，不沿用其他领域成绩。

## 分阶段方案

1. **确定性候选与基线**：先提供命令前缀、AST 槽位/当前环境、当前文档已声明宏、
   保存的公式片段和有效自定义符号候选；补全花括号/上下标/矩阵单元格时提供占位符。
   符号候选携带定义 ID/版本，不只插入一个无法解析的自定义命令。
   不完整编辑状态只用于受限上下文提取，不能因无法严格解析而阻止所有补全；
   完整建议单独经过语法/预算/实际支持范围验证，未支持候选明确标识。
2. **可关闭的本地偏好排序**：先比较固定排序与频率/最近使用/文档范围的轻量权重；
   再评估在线线性排序或选择器模型，不直接训练大模型。默认冷启动保持稳定顺序。
   学习主要依据显式接受、立即撤销和实质修改，不能把展示/悬停等同于正确或接受。
   定制偏好分文档/项目与用户全局两层，切换场景可回退，不让某篇论文习惯污染全部文档。
3. **受控片段续写**：从用户允许使用的历史/公式库检索类似结构，建议下一项、
   配对环境或模板展开。重复历史片段需展示来源；不用选择器本身冒充生成器。
4. **可选生成模型**：只有前述基线证明不足才评估小生成模型；它产生候选，选择器
   排序，Core 做结构/损失检查。以灰色建议、Tab 确认、Esc 拒绝、一次撤销显示；
   推导/等式续写注明未经数学证明，不能自动替换用户已有公式或写入 Office。

## Core 与宿主责任

Core 保持确定性的语法、AST、预算和能力/损失诊断；模型不能改变实际可导出范围。
候选结构接口及可选排序器需独立设计，不能给无模型转换路径添加强制推理依赖。
Office/编辑器负责光标选区、占位符、建议 UI、接受/撤销事务和宿主写入确认。
输入中的新建议需基于当前编辑版本关联；旧异步结果不能覆盖已继续输入的内容。

个人数据和持久化放在可清除的应用层，不在 Core 全局静态对象中积累原始文档。
默认不上传公式/论文，学习和历史检索须可关闭；只记录最小化、限量、可解释的反馈，
允许清空/重置/导入导出个人偏好。敏感/共享文档可不学习；示例数据不得含用户原文。
模型/历史损坏、超时或没有数据时回退确定性候选，不影响编辑、渲染或转换。

## 可验证门禁

- [ ] 命令/环境/占位符/自定义符号有限 fixture，明确不支持与错误输入行为。
- [ ] 光标、选区、中英文/IME、未闭合表达式、撤销/重做和过期异步结果回归。
- [ ] 固定基线与个性化排序对照：Top-1/Top-3、MRR、接受后修改/撤销比例、节省击键；
  记录样本量和按用户/时间隔离的评估，不用同一历史片段同时训练与测试。
- [ ] 语法有效率、未知/不支持候选率、定义缺失率、上下标/操作数结构保留独立统计；
  不将任意一项称为数学准确率。推导建议的数学正确性需另外设计可核验数据集。
- [ ] 提议本地确定性/排序补全 P95 <=50 ms，并测长文档、冷启动、连续输入、内存上限；
  这是目标而非已有结果。生成模型另报首次建议/取消时延，不能拖慢基础路径。
- [ ] 本地持久化/清空/关闭、损坏回退和禁止上传回归；未获同意不采集遥测。
  固定候选 Office 试点已通过最小回归；敏感文档隔离、项目层和更完整交互门禁仍开放。
- [ ] 若评估 contextual bandit，记录实际候选/选择概率与反馈；普通点击历史没有
  未选候选的标签，不能据此宣称无偏离线政策评估。稳定排序基线先于随机探索。
- [ ] 通过独立受控实验验证收益后再考虑默认启用；当前编辑器实验开关仅验证交互，
  不代表质量门禁通过。真实 Office 插入沿用用户确认和原件保留，不关闭宿主门禁。
